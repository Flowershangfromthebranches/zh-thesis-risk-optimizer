# Anti-Shallow Rewrite Check

- [ ] Synonym-only replacement is rejected.
- [ ] Connector-only replacement is rejected.
- [ ] Word-order-only changes are rejected.
- [ ] Active/passive-only changes are rejected.
- [ ] Vague hedge additions are rejected.
- [ ] Effective rewrite requires at least two meaningful actions.
- [ ] Examples compare shallow rewrite and deep rewrite.
- [ ] Deep rewrite preserves facts, citations, and technical terms.
