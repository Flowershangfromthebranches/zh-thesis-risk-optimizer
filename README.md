# zh-thesis-risk-optimizer

面向中文论文的 AIGC 风险与查重相似风险优化 Skill。

本项目用于帮助作者诊断论文文本中的机械化表达、模板化段落、引用保护风险、术语不一致、教材式重复表述等问题，并在不改变研究事实、不破坏引用和技术细节的前提下，给出分段、分章节、分强度的文本质量优化建议。

本项目不是检测结果承诺工具，不替代作者完成研究，也不鼓励掩盖引用来源。它的定位是：中文论文文本质量优化、AIGC 风险诊断、相似表达修复、引用完整性保护和学术规范辅助。

新增能力包括：

本项目不会照搬 thesis-optimizer 中关于检测率阈值的承诺，不承诺任何外部检测系统结果。

## v0.3-report-driven-mapping 新增能力

第三版新增“报告驱动精准定位”工作流：当用户提供查重报告、AIGC 报告、HTML 报告文本、PDF 报告复制文本、Word 颜色标记报告或手动复制的标红片段时，Skill 会先把报告片段映射回论文原文，再生成定点处理任务表。

新增能力包括：

- `REPORT_DRIVEN_MODE`：报告驱动总模式。
- `REPORT_AIGC_ONLY`：根据 AIGC 报告定位高风险段落并定点优化。
- `REPORT_SIMILARITY_ONLY`：根据查重报告定位高重复、高相似、高贡献率片段并处理。
- `REPORT_DUAL_OPTIMIZATION`：同时处理查重报告和 AIGC 报告中的重叠风险。
- `REPORT_TO_SOURCE_MAPPING`：将报告片段、标红内容、相似源说明映射回论文原文。
- `SIMILARITY_SOURCE_HANDLING`：区分引用导致重复、定义重复、教材式背景、综述堆叠、自引过密和不可改保护内容。
- `REPORT_PRIORITY_QUEUE`：按贡献率、风险等级、段落长度和可安全改写程度排序。
- `MAPPING_CONFIDENCE_LEVEL`：为每个映射结果标注 `HIGH`、`MEDIUM`、`LOW` 或 `UNMAPPED`。

本项目不破解检测系统，不伪造检测结果，不承诺检测结果，不替代正规查重和 AIGC 检测；不删除必要引用，也不把他人观点伪装成原创观点。

## v0.2-scoring-diagnosis 新增能力

第二版新增评分诊断与句子级定位能力。评分仅用于提示文本可能存在的模板化、相似表达和改写优先级问题，不等同于知网、维普、万方、Turnitin 或其他检测系统的真实结果。

新增能力包括：

- `SCORING_DIAGNOSIS_MODE`：用户只想先诊断时，输出总体风险、AIGC 风险、查重相似风险和双降优先级。
- `SENTENCE_LEVEL_DIAGNOSIS_MODE`：按段拆句，给每句话标注风险标签、保护标签和处理建议。
- `RISK_LABEL_SYSTEM`：统一使用 AIGC 标签、查重标签和保护标签描述问题。
- `BEFORE_AFTER_SCORE_COMPARISON`：输出改写前后的启发式写作风险评分对比。
- `RISK_HEATMAP_TABLE`：对长文或多段文本按风险热区排序。
- `SAFE_NO_EDIT_ZONE`：识别公式、代码、引用原文、法规标准、参考文献条目、实验数据等不建议自动改写的区域。

所有评分均为启发式写作风险评分，只服务于写作诊断和修订优先级判断。本项目不会真实模拟任何商业检测系统，也不会承诺外部检测结果。

## 为什么要做这个项目

中文论文的文本问题通常不是单一维度：有些段落像机器生成，有些段落与教材、综述或相似来源表述过近，有些段落则因为改写过度而损坏了公式、接口、表名、字段名或引用。本项目把 AIGC 风险、查重相似风险、引用完整性、长文一致性和启发式评分诊断放在同一个工作流里处理，避免简单全文重写带来的新问题。

核心目标：

- 先诊断，再改写，避免无差别重写全文。
- 区分 AIGC 风险和相似风险，按段选择模式。
- 通过句子级定位说明风险来自哪里。
- 通过风险热区表安排长文处理优先级。
- 优先保护引用、数据、结论、术语、公式、代码和工程细节。
- 对系统设计、方法研究、实验分析、理论背景等章节采用不同策略。
- 对长文维护术语表和滚动摘要，减少前后不一致。

## 核心能力

- AIGC 风险诊断：识别模板化起笔、机械三段式、过度对称句式、泛化结尾、模糊归因、AI 高频表达等问题。
- 查重相似风险诊断：识别高重复定义、教材式表述、背景套话、相似源表述过近、引用边界不清等问题。
- 评分诊断：输出总体风险、AIGC 风险、查重相似风险和双降优先级，所有分数均为启发式参考。
- 句子级定位：把段落拆成 S1、S2、S3，标明每句的风险标签、保护标签和处理建议。
- 自动模式选择：按段判断使用 AIGC_ONLY、SIMILARITY_ONLY、DUAL_OPTIMIZATION，或建议不修改。
- 引用完整性保护：保留应引用内容的来源标注，不把他人观点改成无来源原创陈述。
- 工科与理科保护：不误改公式、代码、接口、表名、字段名、参数、缩写和实验条件。
- 长文一致性：维护术语保护清单和滚动段落摘要，避免前后称谓、符号、结论不一致。

## 支持的模式

- `AIGC_ONLY`：只处理模板化、机械化、节奏过均匀、空泛化、泛化结尾等 AIGC 风险。
- `SIMILARITY_ONLY`：只处理重复定义、背景套话、教材式表达、相似源表述过近等查重相似风险。
- `DUAL_OPTIMIZATION`：先处理相似风险，再检查是否产生新的 AI 味，最后复核术语和引用。
- `AUTO_DIAGNOSIS`：用户只提供正文时，自动识别章节、建立保护清单、诊断风险并分段推荐模式。
- `ENGINEERING_SCIENCE_MODE`：用于工科、理科、计算机、系统实现、实验分析等内容，优先保护技术实体。
- `SCORING_DIAGNOSIS_MODE`：只评分和定位，不立即改写。
- `SENTENCE_LEVEL_DIAGNOSIS_MODE`：对段落逐句打标签并给出处理建议。
- `BEFORE_AFTER_SCORE_COMPARISON`：对改写前后文本做启发式评分对比。
- `REPORT_DRIVEN_MODE`：基于用户提供的报告内容做原文映射和定点处理。
- `REPORT_AIGC_ONLY`：只处理 AIGC 报告定位出的风险片段。
- `REPORT_SIMILARITY_ONLY`：只处理查重报告定位出的相似片段。
- `REPORT_DUAL_OPTIMIZATION`：处理报告中的重叠风险和双降优先片段。
- `FULL_THESIS_PROJECT_MODE`：完整论文先建项目总览，不立即重写全文。
- `CHAPTER_TASK_MODE`：按章节拆分任务、验收标准和保护项。
- `PROGRESS_TRACKING_MODE`：维护每章状态、待人工核对项和复测队列。
- `REVISION_LOG_MODE`：记录每次修改目标、强度、保护项和风险变化。
- `ITERATIVE_REVISION_MODE`：根据新报告进行第二轮、第三轮定点优化。
- `PROJECT_HANDOFF_MODE`：生成可恢复上下文的项目交接摘要。

## 支持的报告输入类型

- 查重报告。
- AIGC 报告。
- HTML 报告。
- PDF 报告复制文本。
- Word 颜色标记报告。
- 用户手动复制的标红片段。
- 检测报告中的片段列表。
- 只有高风险段落、没有完整报告的情况。
- 用户提供“原文 + 报告片段 + 相似源说明”的手动结构化输入。

本 Skill 不是实际报告解析程序，除非用户另外开发脚本。它提供的是 AI 代理执行报告理解、片段提取、原文映射和改写决策的规范。报告格式不完整时，应降低置信度并要求人工确认。

## 报告到原文映射流程

1. 确认报告来源和输入类型。
2. 提取报告元信息、风险片段、相似源说明、贡献率和颜色标记含义。
3. 将报告片段映射回论文原文。
4. 标注映射置信度：`HIGH`、`MEDIUM`、`LOW`、`UNMAPPED`。
5. 判断风险类型和保护区域。
6. 生成报告驱动任务表。
7. 只对确认位置且可安全改写的片段做定点处理。
8. 输出人工复核清单。

映射置信度说明：

- `HIGH`：报告片段与原文精确匹配，或只有空格、换行、标点差异。
- `MEDIUM`：报告片段有省略、断句差异，或需要全角/半角、繁简、标点规范化后匹配。
- `LOW`：只能根据关键词、术语或句子片段推断，必须人工确认。
- `UNMAPPED`：找不到原文位置，不得强行改写。

## 相似源处理策略

- 引用导致重复：保留必要引用，可以调整引述方式，不把他人观点写成无来源原创。
- 定义导致重复：保留核心概念，压缩通用定义，转入本文研究语境。
- 教材式背景表述：减少宏大背景套话，转向本文具体问题。
- 相似源表达过近：改变论证顺序和句法结构，补足本文分析角度。
- 综述堆叠：按主题归类，明确不同文献差异，保持引用边界。
- 自引过密：保留必要自引，减少重复段落，说明新论文新增贡献。
- 不可改保护内容：公式、代码、API 路径、表名、字段名、实验数据、图表编号、参考文献条目、法规标准原文、必须逐字引用材料和检测报告原文不直接改写。

## 支持的论文类型

- 中文本科、硕士、课程论文、毕业设计说明书。
- 工科、理科、计算机、管理、教育、社科等中文学术文本。
- Plain Text、从 Word 复制出的正文、LaTeX 混排片段。
- 含检测报告或人工标注高风险段落的论文。

## 不适用场景

- 需要编造实验、数据、访谈、问卷或案例的请求。
- 需要删除必要引用、伪造引用或改动研究结论的请求。
- 需要替作者完成研究内容、实验设计或论文主体创作的请求。
- 需要承诺某个平台检测结果的请求。
- 非中文学术文本的风格化创作。

## 使用示例

### 评分诊断

```text
请用 SCORING_DIAGNOSIS_MODE 先诊断下面这一章，不要改写。输出风险热区表、句子级定位和不建议修改区域。
```

输出会包含启发式评分、风险标签、句子级定位、建议模式和建议强度。

### 句子级定位

```text
请用 SENTENCE_LEVEL_DIAGNOSIS_MODE 分析 P3，每句话标注 AI 标签、查重标签和保护标签。
```

输出会说明可改写句、轻改句、不建议改写句、需要保留引用句和涉及技术保护句。

### 只降 AIGC

```text
请用 AIGC_ONLY 模式处理下面这段毕业论文文字。不要大幅改变语义，不要改动引用和专业术语。
```

输出会包含：风险命中项、改写强度、改写后文本、术语与引用检查。

### 只降查重

```text
请用 SIMILARITY_ONLY 模式处理这段理论背景。重点降低教材式表述和相似源表达过近的问题，保留引用。
```

输出会优先处理定义式、背景式、综述式重复表达，并标注哪些内容必须继续引用。

### 双降

```text
请用 DUAL_OPTIMIZATION 模式处理这一节。先处理相似风险，再检查 AI 味，最后给出引用和术语自检。
```

输出会先做相似表达修复，再做 AIGC 风险复核，最后确认引用、术语、公式、字段名没有被破坏。

### 改写前后评分对比

```text
请对下面的原文和改写稿做 BEFORE_AFTER_SCORE_COMPARISON，只输出启发式评分变化和剩余风险。
```

输出会强调评分不是任何真实检测系统结果。

### 报告驱动映射

```text
下面是论文原文和查重报告标红片段。请用 REPORT_SIMILARITY_ONLY 先映射回原文，再输出报告驱动任务表和定点修改建议。
```

输出会包含映射置信度、相似源处理类型、保护项、建议模式和人工复核清单。

### 完整论文项目初始化

```text
请对我的完整论文建立全文双降项目总览，不要先改写。先输出章节结构、风险热区、保护清单和处理顺序。
```

输出会先生成 `THESIS_MASTER_OVERVIEW`，再建议章节任务拆分。

### 单章任务

```text
只处理第 3 章，目标是双降。请生成章节任务表，不要直接全文重写。
```

输出会生成章节任务、诊断表、改写计划和验收清单。

### 查看进度

```text
显示当前每章处理状态，列出待人工核对和待复测章节。
```

输出会使用 `PROGRESS_TRACKING_MODE` 汇总章节状态。

### 二轮优化

```text
这是新的查重报告，请根据报告更新进度表，只处理残留高风险片段。
```

输出会使用 `ITERATIVE_REVISION_MODE` 生成本轮目标和处理顺序。

### 项目交接

```text
请根据当前总览文档和章节任务文档，生成项目交接摘要，方便下次继续处理。
```

输出会使用 `PROJECT_HANDOFF_MODE` 记录已完成工作、待处理问题和恢复提示。

使用本项目时必须遵守以下底线：

- 不伪造数据。
- 不伪造实验。
- 不伪造引用。
- 不篡改结论。
- 不删除必要引用。
- 不破坏技术术语。

如果某段文字本质上依赖他人观点或通用定义，正确做法是保留引用并改善表达边界，而不是把应引用的内容伪装成原创观点。
