# zh-thesis-risk-optimizer

面向中文论文的 AIGC 风险与查重相似风险优化 Skill。

本项目用于帮助作者诊断论文文本中的机械化表达、模板化段落、引用保护风险、术语不一致、教材式重复表述等问题，并在不改变研究事实、不破坏引用和技术细节的前提下，给出分段、分章节、分强度的文本质量优化建议。

本项目不是检测结果承诺工具，不替代作者完成研究，也不鼓励掩盖引用来源。它的定位是：中文论文文本质量优化、AIGC 风险诊断、相似表达修复、引用完整性保护和学术规范辅助。

## 为什么要做这个项目

中文论文的文本问题通常不是单一维度：有些段落像机器生成，有些段落与教材、综述或相似来源表述过近，有些段落则因为改写过度而损坏了公式、接口、表名、字段名或引用。本项目把 AIGC 风险、查重相似风险、引用完整性和长文一致性放在同一个工作流里处理，避免简单全文重写带来的新问题。

核心目标：

- 先诊断，再改写，避免无差别重写全文。
- 区分 AIGC 风险和相似风险，按段选择模式。
- 优先保护引用、数据、结论、术语、公式、代码和工程细节。
- 对系统设计、方法研究、实验分析、理论背景等章节采用不同策略。
- 对长文维护术语表和滚动摘要，减少前后不一致。

## 核心能力

- AIGC 风险诊断：识别模板化起笔、机械三段式、过度对称句式、泛化结尾、模糊归因、AI 高频表达等问题。
- 查重相似风险诊断：识别高重复定义、教材式表述、背景套话、相似源表述过近、引用边界不清等问题。
- 自动模式选择：按段判断使用 AIGC_ONLY、SIMILARITY_ONLY、DUAL_OPTIMIZATION，或建议不修改。
- 引用完整性保护：保留应引用内容的来源标注，不把他人观点改成无来源原创陈述。
- 工科与理科保护：不误改公式、代码、接口、表名、字段名、参数、缩写和实验条件。
- 长文一致性：维护术语保护清单和滚动段落摘要，避免前后称谓、符号、结论不一致。

## 支持的模式

- `AIGC_ONLY`：只处理模板化、机械化、节奏过均匀、空泛化、泛化结尾等 AIGC 风险。
- `SIMILARITY_ONLY`：只处理重复定义、背景套话、教材式表达、相似源表述过近等查重相似风险。
- `DUAL_OPTIMIZATION`：先处理相似风险，再检查是否产生新的 AI 味，最后复核术语和引用。
- `AUTO_DIAGNOSIS`：用户只提供正文时，自动识别章节、建立保护清单、诊断风险并分段推荐模式。
- `ENGINEERING_SCIENCE_MODE`：用于工科、理科、计算机、系统实现、实验分析等内容，优先保护技术实体。

## 支持的论文类型

- 中文本科、硕士、课程论文、毕业设计说明书。
- 工科、理科、计算机、管理、教育、社科等中文学术文本。
- Plain Text、从 Word 复制出的正文、LaTeX 混排片段。
- 含检测报告或人工标注高风险段落的论文。

## 不适用场景

- 需要编造实验、数据、访谈、问卷或案例的请求。
- 需要删除必要引用、伪造引用或改动研究结论的请求。
- 需要替作者完成研究内容、实验设计或论文主体创作的请求。
- 需要承诺某个平台检测结果的请求。
- 非中文学术文本的风格化创作。

## 使用示例

### 只降 AIGC

```text
请用 AIGC_ONLY 模式处理下面这段毕业论文文字。不要大幅改变语义，不要改动引用和专业术语。
```

输出会包含：风险命中项、改写强度、改写后文本、术语与引用检查。

### 只降查重

```text
请用 SIMILARITY_ONLY 模式处理这段理论背景。重点降低教材式表述和相似源表达过近的问题，保留引用。
```

输出会优先处理定义式、背景式、综述式重复表达，并标注哪些内容必须继续引用。

### 双降

```text
请用 DUAL_OPTIMIZATION 模式处理这一节。先处理相似风险，再检查 AI 味，最后给出引用和术语自检。
```

输出会先做相似表达修复，再做 AIGC 风险复核，最后确认引用、术语、公式、字段名没有被破坏。

### 自动诊断

```text
下面是论文正文，请先识别章节结构，建立术语保护清单，再输出每段适合的处理模式。
```

输出会先给诊断表，再按用户确认的优先级分段修改。

## 学术诚信说明

使用本项目时必须遵守以下底线：

- 不伪造数据。
- 不伪造实验。
- 不伪造引用。
- 不篡改结论。
- 不删除必要引用。
- 不破坏技术术语。
- 不误改公式、代码、接口、表名、字段名和参数。

如果某段文字本质上依赖他人观点或通用定义，正确做法是保留引用并改善表达边界，而不是把应引用的内容伪装成原创观点。
