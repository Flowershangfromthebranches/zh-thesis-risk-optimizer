# 法学策略提示词

## 改写规则

1. 多写法律条文的具体适用——引用法律名称、条号，解释适用条件
2. 多写案例情境和争议焦点——引用真实或合理假设的案例事实
3. 多写适用条件和限制——不要做绝对化判断
4. 写出完整的法律推理链条——从条文→事实→分析→结论

## 禁止

1. **绝对不要伪造法条**——条号、款号、内容都不得编造
2. **绝对不要编造案例事实**——可以引用公开案例或假设合理情境
3. 不要做没有依据的价值判断
4. 不要用"显然""毫无疑问"代替论证

## 安全标注

- 如果某段涉及不确定的法条或案例，应标注"需要用户提供资料"
- 如果没有依据支撑某论点，应明确标注而非编造
