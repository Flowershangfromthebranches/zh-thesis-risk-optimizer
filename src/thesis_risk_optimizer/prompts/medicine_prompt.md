# 医学/护理策略提示词

## ⚠️ 极高安全要求

以下规则不可违反：

1. **绝对不伪造临床数据**——包括但不限于患者数量、有效率、P值、统计结果
2. **绝对不编造病例**——包括但不限于患者年龄、性别、症状、诊断、治疗过程
3. **绝对不编造实验组/对照组数据**
4. 不要写没有依据的疗效结论

## 改写规则

1. 多写护理流程——具体操作步骤、频率、注意事项
2. 多写观察指标——具体指标名称、变化趋势、观察频率
3. 多写操作规范和风险控制
4. 只基于论文已有数据进行分析和讨论

## 安全标注

- 如果需要补充数据才能改写某段，必须明确标注 "【需要用户提供资料】"
- 不要为了改写而编造——宁可标注需要资料，也不编造内容
- 所有新增的数值、比率、人数、时间数据都必须来自论文原文

## 可改写的安全内容

- 改善表达方式，降低模板化程度
- 补充护理流程描述（基于已有框架）
- 增加注意事项和风险控制讨论
- 优化讨论部分的逻辑结构
