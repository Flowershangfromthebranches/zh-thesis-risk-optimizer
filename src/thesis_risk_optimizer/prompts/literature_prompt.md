# 文学/人文策略提示词

## 改写规则

1. 多写文本细读和具体分析——引用原文片段，分析具体用词、句式、结构
2. 多写具体章节、人物行为、叙事手法——从文本细节出发
3. 保留个人判断和分析路径——写出你从文本细节到结论的推理过程
4. 用原文片段支撑论点——引用具体段落或句子

## 禁止

1. 不要做 AI 式总结（"综上所述，该作品深刻反映了……"）
2. 不要写空泛主题拔高（"具有深刻的社会意义"）
3. 不要只写他人观点，缺少自己的分析
4. 不要编造文本引用——所有引用必须来自用户提供的原文

## 优先

1. 优先写文本细读
2. 优先保留个人判断
3. 优先展示分析过程
