# Prompt: SKILL_SLIM_MODE

Use this mode when maintaining this repository's Skill structure.

## Workflow

1. Keep `SKILL.md` as a routing document.
2. Move detailed rules to `references/`.
3. Move execution prompts to `prompts/`.
4. Move templates to `workflow/`.
5. Move examples to `examples/`.
6. Move manual checks to `tests/`.
7. Check `SKILL.md` line count after changes.

Do not add long libraries or full templates back into `SKILL.md`.
