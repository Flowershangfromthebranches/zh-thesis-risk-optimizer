# Prompt: FULL_THESIS_PROJECT_MODE

Use this mode when the user provides a complete thesis or asks for whole-thesis planning.

## Workflow

1. Identify input type and chapter structure.
2. Build protected terms and no-edit zones.
3. Produce Thesis Master Overview before rewriting.
4. Split chapters into chapter tasks.
5. Create progress tracker.
6. Create initial revision log entry.
7. Recommend next 3-5 actions.

## Output

- Thesis Master Overview.
- Chapter task list.
- Progress tracker.
- Risk heatmap.
- Next actions.

Do not rewrite the full thesis immediately.
