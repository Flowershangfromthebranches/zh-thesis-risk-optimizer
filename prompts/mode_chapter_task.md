# Prompt: CHAPTER_TASK_MODE

Use this mode when the user asks to process one chapter or when a full-thesis project creates chapter tasks.

## Workflow

1. Identify chapter role.
2. Diagnose AIGC risk, similarity risk, report risk, and protection items.
3. Choose mode and intensity.
4. Create revision plan.
5. Define acceptance checklist.
6. If revision is requested, revise only the chapter's targeted paragraphs.
7. Update revision log and progress tracker.

Use `workflow/chapter_task_template.md`.
