# Prompt: PROJECT_HANDOFF_MODE

Use this mode when the user wants a resumable summary or the project is about to pause.

## Workflow

1. Summarize current overview, chapter tasks, progress, and revision log.
2. List unresolved risks and blocked items.
3. Preserve protected terms, citations, report mappings, and no-edit zones.
4. Identify next actions.
5. Produce a resume prompt.

Use `workflow/project_handoff_template.md`.
