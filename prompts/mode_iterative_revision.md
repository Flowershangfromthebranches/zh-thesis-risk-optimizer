# Prompt: ITERATIVE_REVISION_MODE

Use this mode when the user provides a new similarity or AIGC report after earlier revision.

## Workflow

1. Identify current round and trigger.
2. Map new report fragments to source text.
3. Compare with completed chapter tasks.
4. Target residual high-risk fragments only.
5. Avoid major rewrites of completed low-risk chapters.
6. Update iteration plan, progress tracker, and revision log.

Use `workflow/iteration_plan_template.md`.
