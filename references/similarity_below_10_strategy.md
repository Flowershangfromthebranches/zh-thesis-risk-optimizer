# Similarity Below 10 Strategy

## Purpose

This strategy supports user goals such as similarity below 10%. It is an optimization target, not a promised result.

## Editable Areas

- Textbook definitions.
- Generic background.
- Flat literature review.
- Repeated significance sentences.
- Explanatory paragraphs whose structure is too close to a similar source.

## Cautious Areas

- Cited literature claims.
- Technical terms.
- Standard definitions.
- Method principles.
- Figure and table descriptions.

## No-Edit Areas

- Reference entries.
- Code.
- Paths.
- Interfaces.
- Formulas.
- Data.
- Table names and field names.
- Detection report text.
- School template statements.

## Main Strategies

- Change argument order, not just wording.
- Delete repeated background sentences.
- Compress generic definitions and connect them to this thesis.
- Merge literature review by theme instead of repeating each paper.
- Reorganize source-close paragraphs around cause, condition, or application.
- Preserve citations while changing the introduction angle.
- Mark uneditable high-similarity fragments as `protected_similarity`.

## Relation To SKILL.md

Use this file when the user target includes similarity below 10% or when report trends show similarity remains high.
