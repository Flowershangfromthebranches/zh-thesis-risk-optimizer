# Structure Rebuilding Rules

## Purpose

`STRUCTURE_REBUILDING_RULES` provides paragraph-level rebuild templates for stronger AIGC-risk reduction and better similarity-risk handling.

## Background Paragraph

Common weak structure:

- Macro background -> technology importance -> generalized significance.

Recommended structure:

- Concrete problem -> current handling weakness -> why this thesis object needs the problem solved.

## Theoretical Basis Paragraph

Common weak structure:

- Definition -> features -> importance.

Recommended structure:

- Concept boundary -> why this thesis uses the concept -> relation to the system, experiment, or research object.

## System Design Paragraph

Common weak structure:

- Uses an architecture -> has advantages -> improves efficiency.

Recommended structure:

- Module responsibility -> data flow or call relation -> design tradeoff -> protected boundary.

## Implementation Paragraph

Common weak structure:

- Implements a function -> user can operate -> system is more convenient.

Recommended structure:

- Input -> validation -> processing -> storage/return -> exception handling.

## Experiment Analysis Paragraph

Common weak structure:

- Results show -> metric improves -> method is effective.

Recommended structure:

- Test condition -> observed result -> reason explanation -> applicable boundary or limitation.

## Conclusion Paragraph

Common weak structure:

- Completed system -> has significance -> future outlook.

Recommended structure:

- Completed work -> actual limitation -> verifiable conclusion -> concrete next optimization.

## Safety Boundaries

- Do not add unsupported objects, data, modules, experiments, or conclusions.
- Preserve citations, formulas, technical names, and numeric values.
