# Similarity Source Handling

Use these rules after mapping a similarity-report fragment back to the thesis source text.

## 1. Citation-Caused Similarity

Handling:

- Check whether citation markers are present.
- Keep necessary citations.
- Adjust the quotation or paraphrase style when safe.
- Convert direct quotation to summarized paraphrase only when meaning and citation boundary remain intact.
- Do not disguise another author's view as an uncited original claim.

## 2. Definition-Caused Similarity

Handling:

- Preserve the core concept.
- Compress generic definition wording.
- Place the concept into the thesis context.
- Reduce textbook-like original phrasing.
- Do not distort the concept.

## 3. Textbook-Like Background

Handling:

- Reduce broad openings such as "随着时代发展" or "在互联网快速发展背景下".
- Move toward the thesis-specific problem.
- Add the research object, system scenario, experiment object, or problem boundary when already known.

## 4. Source-Close Expression

Handling:

- Change argument order.
- Change syntax structure.
- Add the thesis's own analytical angle.
- Add or preserve citation when needed.
- Do not rely on synonym replacement only.

## 5. Literature Review Stacking

Handling:

- Group studies by topic.
- Merge repeated viewpoints carefully.
- Explain differences among sources.
- Keep citation boundaries visible.

## 6. Dense Self-Citation

Handling:

- Check whether the repeated content comes from the author's prior work.
- Keep self-citation when necessary.
- Reduce repeated paragraphs.
- Make the new contribution of the current thesis explicit.

## 7. Protected No-Edit Content

Includes:

- Formulas.
- Code.
- API paths.
- Database table names.
- Field names.
- Experimental data.
- Figure/table numbers.
- Reference entries.
- Legal or standard text.
- Required direct quotations.
- Detection report text.

Handling:

- Do not rewrite directly.
- Only revise surrounding explanatory prose.
- Require human confirmation if the protected content itself must change.
