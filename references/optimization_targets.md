- Similarity target: below 10%.
- AIGC target: below 20%.

## Interpretation

- Targets are optimization directions, not guaranteed results.
- Any concrete percentage must come from a user-provided report.
- This Skill must not simulate, crack, reproduce, or promise any commercial detection system.
- When the user provides multi-round reports, use report trends to judge whether the draft is approaching the targets.
- If the target is still far away, recommend staged local treatment rather than promising one-pass completion.

## Escalation

When current results remain far from the target:

- Do not continue blind synonym rewriting.
- Output locations that need more content evidence.
- Output an author supplementation list.
- Output next-round priority.
- Protect citations, data, code, formulas, interfaces, table names, fields, and report facts.
