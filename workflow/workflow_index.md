# Workflow Index

Use these templates for full-thesis project management.

| Need | Template |
|---|---|
| Full project overview | `workflow/thesis_master_overview_template.md` |
| Chapter-level task | `workflow/chapter_task_template.md` |
| Status tracking | `workflow/progress_tracker_template.md` |
| Revision history | `workflow/revision_log_template.md` |
| Second/third pass plan | `workflow/iteration_plan_template.md` |
| Resume after interruption | `workflow/project_handoff_template.md` |

Rules:

- Generate overview before rewriting a full thesis.
- Generate chapter tasks before chapter revision.
- Update progress after each meaningful stage.
- Record revision logs whenever text is changed.
- Use handoff when the task pauses, context changes, or a new model/session continues the project.
