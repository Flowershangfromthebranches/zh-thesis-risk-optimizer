# Author Evidence Pack Template

Use this template when a human resource management or management/social-science thesis has red/orange AIGC report paragraphs but lacks enough local evidence for safe rewriting.

Do not fabricate any answer. If a field is unavailable, write `无` or `暂不能提供`.

```text
【论文题目】

【公司/组织名称】

【A公司招聘流程真实步骤】
示例：用人部门提交需求 -> HR发布岗位 -> 简历筛选 -> 初试 -> 复试 -> offer -> 入职跟踪

【各环节负责人】
示例：用人部门负责人、HR专员、部门经理、总经理

【平均招聘周期】
示例：普通岗位约__天，关键岗位约__天

【难招岗位】
示例：技术岗、运营岗、销售岗、管理岗等

【问卷最低分题项】
请写题项名称、分值或比例：

【访谈原话或访谈摘要】
请注明来自 HR、用人部门、应聘者、新员工或管理者：

【渠道占比】
示例：招聘网站__%，内推__%，校园招聘__%，社交媒体__%，猎头__%

【简历筛选方式】
示例：人工筛选 / 表格筛选 / 系统关键词筛选 / 用人部门二次筛选

【面试评价表是否存在】
存在 / 不存在 / 不清楚
如果存在，请写主要评价维度：

【试用期流失岗位】
请写岗位类型、人数或现象描述：

【当前系统/表格工具】
示例：Excel、飞书表格、企业微信、招聘平台后台、纸质表单等

【可写入论文但不能编造的数据】
请列出可安全写入正文的数据、比例、周期、岗位、流程、表单或访谈摘要：

【不能写入或不确定的信息】
请列出需要保密、未经确认、不能写入论文的信息：
```

## Usage Rule

When a red/orange paragraph needs company, questionnaire, interview, process, post, form, indicator, responsibility, review-cycle, or boundary evidence but the thesis does not provide it, stop and request this pack.

Do not replace missing evidence with generic phrases such as "构建体系", "提升效率", "优化流程", "强化能力", "丰富渠道", "数据驱动", "智能高效", or "提供参考".
