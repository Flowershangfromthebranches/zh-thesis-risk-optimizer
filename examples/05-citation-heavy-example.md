# Example 05: Citation-Heavy Paragraph

## User Intent

处理引用密集段落，降低相似表达和机械综述风险。

## Before

张三等[1]提出了基于图像增强的检测方法，李四等[2]提出了基于深度学习的检测方法，王五等[3]提出了基于多尺度特征融合的检测方法。这些研究为本文提供了重要参考。

## Diagnosis

| Risk | Reason |
| --- | --- |
| 综述堆叠 | 多篇文献使用同一种句式 |
| 泛化结尾 | “重要参考”没有说明参考点 |
| 引用保护 | [1]、[2]、[3] 必须保留 |

## After

现有研究可以按技术路径分成三类：张三等[1]侧重图像增强，主要解决输入质量不足的问题；李四等[2]将深度学习用于检测环节，重点在特征自动提取；王五等[3]则通过多尺度特征融合处理目标尺度变化。本文后续方法设计主要借鉴第二类研究的特征提取思路，同时保留第三类研究中对尺度差异的处理意识。

## Citation Integrity

- [1]、[2]、[3] 均保留。
- 各文献贡献没有被混成无来源结论。
- “本文借鉴什么”被具体化。
