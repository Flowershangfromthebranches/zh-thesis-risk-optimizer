# Example 08: Sentence-Level Risk Location

## P1

随着人工智能技术的快速发展，其在教育领域的应用具有重要意义。首先，人工智能能够提升教学效率；其次，人工智能能够促进个性化学习；最后，人工智能能够推动教育信息化建设。已有研究指出，智能推荐系统可以改善学习资源匹配效果[6]。

### Diagnosis

段落编号：P-001

综合风险：高

建议模式：DUAL_OPTIMIZATION

建议强度：L2

句子级定位：

- S1：[AI-模板化起笔][查重-背景套话] 建议中度改写。
- S2：[AI-机械三段式][AI-过度对称][查重-常见结论表达] 建议重写句法结构。
- S3：[保护-必要引用][查重-来源边界不清] 保留引用，不要把文献观点写成原创观点。

处理建议：

- 可改写句：S1、S2。
- 轻改句：无。
- 不建议改写句：无。
- 需要保留引用句：S3。
- 涉及术语/公式/代码保护句：无。

## P2

系统通过 `/api/user/profile` 获取用户基础信息，并将心率、血氧和记录时间写入 `health_record` 表中的 `heart_rate`、`blood_oxygen` 和 `record_time` 字段。该设计形成了完整闭环，能够显著提升系统运行效率。

### Diagnosis

段落编号：P-002

综合风险：中

建议模式：AIGC_ONLY + ENGINEERING_SCIENCE_MODE

建议强度：L1

句子级定位：

- S1：[保护-接口路径][保护-数据库表名][保护-字段名][保护-实验参数] 不建议大改，只能优化解释性文字。
- S2：[AI-万能意义句][AI-绝对化断言][AI-宣传式表达] 建议轻度改写，避免扩大结论。

处理建议：

- 可改写句：S2。
- 轻改句：S1 的非技术说明部分。
- 不建议改写句：S1 中的接口、表名、字段名。
- 需要保留引用句：无。
- 涉及术语/公式/代码保护句：S1。
