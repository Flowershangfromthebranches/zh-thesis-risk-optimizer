# Example 20: Skill Slimming

## Before

`SKILL.md` contains full rule libraries, full report-mapping details, full label lists, and full workflow templates.

## After

`SKILL.md` keeps:

- Role.
- Scope.
- Non-goals.
- Core principles.
- Mode router.
- Standard workflow.
- Output format index.
- Safety boundaries.
- Reference index.

Details move to:

- `references/` for rules.
- `prompts/` for task prompts.
- `workflow/` for templates.
- `examples/` for examples.
- `tests/` for checks.
